# KirauI Content Management System

KirauI is a lightweight content management system (CMS) developed with PHP and MySQL, offering comprehensive article management, user authentication, commenting features, and rich customization options.

## 🚀 Quick Installation

### System Requirements
- PHP 8.0 or higher
- MySQL 9.0 or higher
- PDO extension
- OpenSSL extension (for email encryption)
